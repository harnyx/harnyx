answer key and two solver results. The current draft is the task being tested;
the original seed is provenance, not an immutable grading target.
Private answers and operator assessments support comparison, not assumptions about

chunks and grounded-worker responses. Its search_worker_responses lists worker

Worker ordering is observable; quote decisive queries verbatim and short result

REPORT

Write one concise section per solver and a comparison. Identify the earliest
observable answer or answer-identifying record, what useful information was
recovered, the relationship supplying it and the later queries it enabled.
Cite archive filename, solver role and worker-call number or provider-chunk index.
One result can supply several downstream inputs; preserve those transitions.

Distinguish bypass, intended traversal and unresolved retrieval. Neither search
counts nor being searchable proves ease; missing evidence is not proof of bypass.
Successful intended traversal can still reveal inputs worth concealing or steps
to extend. Describe unresolved searches without labeling them demonstrated shortcuts.
Explain wrong turns, completed wrong answers, contradictions and evidence limits;
API failures are not incorrect answers. State uncertainty rather than invent causes.
